# 🎓 CGPA Calculator (Regular) – Nnamdi Azikiwe University

## 📖 Overview

This project is an **Excel-based CGPA Calculator** developed for undergraduate students of **Nnamdi Azikiwe University (UNIZIK)**. It automates the calculation of both **Semester Grade Point Average (GPA)** and **Cumulative Grade Point Average (CGPA)** using the University's official grading system.

The workbook enables students to record their academic performance semester by semester while automatically computing GPAs, helping them monitor their academic progress throughout their degree programme.

---

## ✨ Features

- 📊 Automatic Semester GPA calculation
- 📈 Automatic Cumulative GPA (CGPA) calculation
- 📝 Supports multiple academic sessions and semesters
- 🎯 Uses the official UNIZIK grading system
- ➗ Automatically calculates Quality Points
- 📚 Organised and easy-to-use Excel interface
- ✅ No programming knowledge required

## 🚀 How to Use

1. Download or open the Excel workbook.
2. Enter your personal information (if applicable).
3. Input each course with the following details:
   - Course Code
   - Course Title
   - Credit Unit
   - Grade Obtained
4. The workbook will automatically calculate:
   - Grade Points
   - Quality Points
   - Semester GPA
   - Cumulative GPA (CGPA)

---

## 🧮 Calculation Formula

### Quality Point

```text
Quality Point = Credit Unit × Grade Point
```

### Semester GPA

```text
GPA = Total Quality Points ÷ Total Credit Units
```

### Cumulative GPA (CGPA)

```text
CGPA = Total Cumulative Quality Points ÷ Total Cumulative Credit Units
```
